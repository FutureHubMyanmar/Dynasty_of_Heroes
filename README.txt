DYNASTY OF HEROES - CINEMATIC WEBSITE V1.2 REVIEW

HOW TO OPEN
Extract entire ZIP (do not open index.html from inside ZIP). Open DOH_Cinematic_Website/index.html with Chrome or Edge. If your browser restricts local assets, use static hosting or run `python -m http.server 8000` inside DOH_Cinematic_Website then open http://localhost:8000.

PAGES TO REVIEW
Home, Story, Characters, Comics, Animation, Soundtrack, Game.
Comic reader: Prologue & Episodes 1-5, full 45 pages each English and Myanmar; Single / Double / Scroll; page thumbnails, zoom, fullscreen, reading progress.
Characters: clean cropped images; Mg Kyan and King Kyan naming. Source comic artwork still contains the originally printed names.
Game: Princess Pyin Sa unit image replaced with complete body from tactical reference.
Music: four songs included.
